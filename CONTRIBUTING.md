# Contributing

1. Create a focused branch for your change.
2. Install dependencies with `npm install` and copy `.env.example` to `.env`.
3. Keep server-side permission checks in domain actions and validate input with Zod.
4. Add or update tests for changed behavior.
5. Run `npm run lint`, `npx tsc --noEmit`, and the relevant test suites before opening a pull request.
6. Never commit `.env`, credentials, private uploads, or real learner data.

Use accessible semantic HTML, support keyboard interaction and reduced motion, and preserve the product's quiet visual style.
